# Передача артбордів Anna → збірка прототипу

Гілка `anna-handoff` — лише для передачі файлів з полотна Claude Design. Сайт (GitHub Pages) збирається з гілки `main`, цю гілку він не публікує.

## Структура однієї передачі

```
handoff/<РРРР-ММ-ДД>-<коротка-назва>/
  manifest.json        # що передано і що змінено
  project/             # артборди .dc.html — без змін, як на полотні (імена файлів теж як на полотні)
  assets/              # кожен файл, на який посилається /_blob/<id>, з іменем <id>.<розширення>
```

`manifest.json`:

```json
{
  "date": "2026-11-04",
  "author": "Anna",
  "artboards": [
    { "file": "Catalog-v5-....dc.html", "page": "catalog", "viewport": "desktop", "changes": "що змінилося, коротко" },
    { "file": "Mobile-Catalog-v5-....dc.html", "page": "catalog", "viewport": "mobile", "changes": "..." }
  ],
  "notes": "усе, що варто знати збирачу"
}
```

`page`: home | catalog | product | ui-kit | інша назва. `viewport`: desktop | mobile | both.

## Правила

- Файли не редагувати й не форматувати: збирач порівнює їх із попередніми версіями.
- Кожен `/_blob/<id>`, що трапляється в артбордах, має лежати в `assets/` (шрифти й картинки теж, навіть якщо вони вже передавалися).
- Одна передача — один коміт: `handoff: <дата> <що передано>`. Пуш у `anna-handoff`, не в `main`.
- Попередні передачі не видаляти й не переписувати.
